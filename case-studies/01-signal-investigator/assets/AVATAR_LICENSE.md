# Maxim's avatar

Chosen source: DiceBear **Avataaars** style, original design by Pablo Stanley.

- Style: https://www.dicebear.com/styles/avataaars/
- License information: https://www.dicebear.com/licenses/
- Fixed generated avatar URL: https://api.dicebear.com/10.x/avataaars/svg?seed=MaximSignalInvestigator
- DiceBear documents this style as **free for personal and commercial use**.

Run `python scripts/fetch_maxim_avatar.py` once on your Mac to download and
bundle `assets/maxim-avatar.svg` for self-contained deployment. Keep this
license notice and the app footer attribution when publishing.

The app falls back to the official DiceBear API URL when the file is absent.
